# Paltra

Paltra is a web-based operations platform designed to centralize warehouse information, minimize errors, and improve visibility across operational teams.

## Key Features

* Live load and truckload tracking
* Changeover and call-in management
* Dock door and shipment status updates
* Line count and dimension tracking
* Manifest error documentation
* Role-based access and department-specific views
* Automated notifications and daily workflow resets
* CSV reporting and data exports
* Mobile-friendly interface

## Purpose

Paltra was created to reduce reliance on disconnected spreadsheets, emails, and manual tracking processes. The platform gives users a clearer way to find operational information, update statuses, and complete routine tasks.

## Technologies

* Typescript
* HTML and CSS
